# Changelog

All notable changes to Portainer Fleet Updater are documented here.

## 0.1.0 - 2026-10-24

- Initial public project baseline.
- Apache License 2.0, matching Postmaster MCP.
- Versioned single-YAML Portainer deployment pattern derived from Postmaster MCP.
- Stable SemVer release resolver: `latest` means the highest non-draft, non-prerelease `vX.Y.Z` GitHub Release.
- Persistent release cache, atomic activation and last-known-good fallback.
- Read-only Portainer discovery dashboard.
- Automatic discovery of Portainer Server, environments and stacks.
- Persistent local selection of managed stacks using checkboxes.
- No Portainer/Agent/stack update actions are enabled in this release.
